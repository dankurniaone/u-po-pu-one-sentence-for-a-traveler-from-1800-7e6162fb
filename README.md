A [make.fun](https://make.fun/competitions/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) entry: one sentence of at most 200 characters explaining the modern internet to someone arriving from 1800.

## The sentence

> Imagine every library and post office in the world joined by one road, so a letter you send is answered before the ink dries and any book you ask for opens at once.

Built from what a person from 1800 already knows — a road, a post office, a library — with no word coined after their time, and one image to remember: a letter answered before the ink dries.

## Run

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt` (164 characters, single line, valid UTF-8), after checking the 1–200 character gate and verifying the file round-trips exactly.
